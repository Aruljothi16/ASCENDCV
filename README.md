# ASCENDCV
AscendCV is an AI-powered resume analysis tool built using Streamlit and Python. It intelligently analyzes your resume against any job description, identifies skill gaps, generates improvement plans, and provides actionable insights to enhance your profile for better ATS (Applicant Tracking System) compatibility and job readiness.

# Key Features

# 1.AI Resume Analysis

Extracts technical and soft skills automatically.

Compares resume content with a given job description.

Calculates an advanced match percentage using NLP and TF-IDF.

# 2.Skill Gap Detection

Identifies missing technical and soft skills.

Provides personalized learning plans with curated online resources.

# 3.Profile Summary Generation

Generates detailed summaries with strengths, weaknesses, and improvement recommendations.

Assesses experience level, education, and quantified achievements.

# 4.Learning Path & Projects

Offers 1-week intensive learning plans for missing skills.

Suggests relevant mini-projects to boost portfolio strength.

# 5.Professional Resume Generator

Generates enhanced resumes as downloadable PDFs with missing skills and new project ideas included.
